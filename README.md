# 📊 Credit-Wise Automated Loan Risk & Eligibility System

An end-to-end Machine Learning classification pipeline designed to analyze credit eligibility and predict default risks using financial applicant data.

## 🛠️ Tech Stack & Tools
- **Language:** Python.
- **Libraries:** Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn.
- **Techniques:** SMOTE (Class Imbalance), RobustScaler (Feature Scaling), Optuna (Hyperparameter Tuning)
- **BI & Visualization:** Power BI, Matplotlib, Seaborn.
- **Database:** SQL
  
## 🚀 Key Features & Workflow
- **Data Preprocessing & EDA:** Handled missing values, out-of-range records, and feature scaling using RobustScaler.
- **Handling Class Imbalance:** Applied **SMOTE** to balance default class distribution for unbiased model training.
- **Model Optimization:** Automated hyperparameter tuning via **Optuna** to achieve an impressive **92% Accuracy**.
- **Dashboarding:** Integrated model findings into an executive summary Power BI dashboard for real-time risk tracking.

## 📈 Results
- Achieved **92% Classification Accuracy** in predicting high-risk default applicants.
- Reduced manual underwriting risk evaluation time through automated eligibility pipelines.
