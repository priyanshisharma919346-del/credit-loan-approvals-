# 📊 Credit-Wise Automated Loan Risk & Eligibility System

An end-to-end Machine Learning classification pipeline designed to analyze credit eligibility and predict default risks using financial applicant data.

## 🛠️ Tech Stack & Tools
- **Language:** Python[cite: 1]
- **Libraries:** Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn[cite: 1]
- **Techniques:** SMOTE (Class Imbalance), RobustScaler (Feature Scaling), Optuna (Hyperparameter Tuning)[cite: 1]
- **BI & Visualization:** Power BI, Matplotlib, Seaborn[cite: 1]
- **Database:** SQL[cite: 1]

## 🚀 Key Features & Workflow
- **Data Preprocessing & EDA:** Handled missing values, out-of-range records, and feature scaling using RobustScaler[cite: 1].
- **Handling Class Imbalance:** Applied **SMOTE** to balance default class distribution for unbiased model training[cite: 1].
- **Model Optimization:** Automated hyperparameter tuning via **Optuna** to achieve an impressive **92% Accuracy**[cite: 1].
- **Dashboarding:** Integrated model findings into an executive summary Power BI dashboard for real-time risk tracking[cite: 1].

## 📈 Results
- Achieved **92% Classification Accuracy** in predicting high-risk default applicants[cite: 1].
- Reduced manual underwriting risk evaluation time through automated eligibility pipelines[cite: 1].
